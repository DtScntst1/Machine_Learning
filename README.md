This repository serves as a portfolio of my core Machine Learning projects. It includes implementations of various supervised and unsupervised learning algorithms to solve real-world regression, classification, and clustering problems.

## Overview
- **Objective:** To build robust predictive models and understand the mathematical mechanics behind core ML algorithms.
- **Techniques Used:** Linear/Logistic Regression, Decision Trees, Random Forests, Support Vector Machines (SVM), and K-Means Clustering.
- **Workflow:** Feature engineering, train-test splitting, cross-validation, hyperparameter tuning (GridSearchCV), and model evaluation (Accuracy, F1-Score, RMSE).

## Tech Stack
- **Machine Learning:** Scikit-Learn, XGBoost
- **Data Manipulation:** Pandas, NumPy
